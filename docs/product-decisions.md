# Решения по UX и источникам

Дата: 08.09.2026 (обновлено).

## Простой основной сценарий

Студент обычно знает название своей группы. Главный вход — поиск с подсказками, клавиатурой и сохранением выбора. Регистр, пробелы и разные тире нормализуются.

Уровень образования (из кода группы: Б/М/С/А) — в блоке «Уточнить поиск». Фильтр института скрыт, пока API не отдаёт институты в каталоге. После выбора группы — неделя и подгруппа над днями.

## Подгруппы

- Список строится из каталога группы и полей занятий.
- Выбор `1` показывает занятия для 1 и общие (без пометки).
- Пустая подгруппа на карточке не подписывается.
- Одинаковые пары разных подгрупп можно склеить в карточку; разные аудитории/преподаватели — нет.

## Визуальный характер

Палитра МИСИС (`#0541F0`, `#0A1E64`, `#37EBFF`), тёмный UI (`#0C1018` / `#131B28`), шрифт Golos Text. Неофициальный сервис без логотипа университета.

## Источник расписания

Live JSON-RPC `edu.misis.ru`: каталог с TTL, расписание по группе/неделе с TTL и лимитом размера кэша, rate limit на `/api/schedule`. Смена бэкенда — через `ScheduleProvider` в `composition.py` ([architecture.md](architecture.md)).

## Приоритеты

**Сделано (база):** live API, единый контракт, Docker, opaque 502, кэш с eviction, shared HTTP, security headers, UX без мигания при смене недели, rate limit.

**P1 дальше:** отображение ближе к сайту МИСИС при склейке ячеек; readiness probe; structured logs; стабильный `revision` каталога.

**P2 позже:** CSP, метрики, лимиты ресурсов в compose, явные институты если появятся в API.
