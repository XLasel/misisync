# Misisync

Веб-приложение с расписанием МИСИС: поиск учебной группы, занятия по дням недели, преподаватели, аудитории и фильтр подгрупп. Интерфейс на русском языке, адаптивный для телефона и компьютера. Группа и подгруппа сохраняются на устройстве.

Самостоятельная Git-репа находится в `/Users/xlasel/misisync`, основная ветка — `main`. Первоначальная копия в зеркале проекта ChatGPT больше не является рабочей. База и зависимости остаются локальными и исключены из Git; удалённый репозиторий не создавался.

Основной вход — поиск с подсказками. Необязательные фильтры института и уровня образования находятся в «Уточнить поиск». [Решения по UX, стилю и исследованию API](docs/product-decisions.md).

**Стек:** Python / FastAPI, стандартный `sqlite3` и SQL без ORM, Vue 3 / Nuxt 4, Docker Compose. Nuxt работает как Node-сервер и проксирует API в контейнер Python; браузеру не нужен отдельный адрес бэкенда или CORS.

## Запуск

Нужны Docker Engine / Docker Desktop с запущенной службой Docker и Docker Compose v2. Из корня проекта:

```sh
docker compose up --build -d
```

Открыть [http://localhost:3000](http://localhost:3000). При первом запуске группы появятся после загрузки расписания. Интерфейс автоматически проверяет состояние раз в минуту. Никаких демонстрационных занятий в базе нет.

Настройки по умолчанию уже заданы в Compose. Чтобы изменить их, сначала скопируйте `.env.example` в `.env` и отредактируйте нужные значения:

```sh
cp .env.example .env
docker compose up --build -d
```

Посмотреть состояние и журналы:

```sh
docker compose ps
docker compose logs -f backend
```

Остановить приложение, сохранив расписание:

```sh
docker compose down
```

SQLite хранится в именованном томе `schedule_data`, подключённом к `/data` в бэкенде. Перезапуск, пересборка и `docker compose down` его сохраняют. **`docker compose down -v` удаляет том и расписание.** При изменении `DATABASE_PATH` оставляйте файл внутри `/data`.

## Источник и обновление

Исходная точка — [страница студентов МИСИС](https://misis.ru/students/). Она ведёт на [расписание учебных занятий](https://misis.ru/students/schedule/), где опубликованы отдельные файлы институтов. На 8 сентября 2026 года источник содержит один XLSX и восемь XLS. Поэтому реализованы оба формата: `openpyxl` для XLSX и `xlrd` для XLS.

После старта бэкенда импорт запускается сразу, затем каждые четыре часа после завершения предыдущей попытки. Поиск ссылок повторяется при каждом обновлении, поэтому переименование файла с новой датой не требует изменения конфигурации. Можно указать конкретный файл через `SOURCE_URL` или отфильтровать институт через `SOURCE_LINK_PATTERN`.

Порядок обновления:

1. Найти ссылки на XLS/XLSX на исходной странице или странице расписания, в пределах того же сайта.
2. Скачать все выбранные файлы с ограничениями времени и размера.
3. Разобрать таблицы в памяти, проверить структуру, дни и время.
4. В одной транзакции SQL заменить группы, занятия и время успешной загрузки.

При сетевой ошибке, повреждённом файле, неподдерживаемой структуре распознанной сетки или ошибке записи транзакция не заменяет предыдущую версию. Ошибка одного выбранного института отменяет весь импорт. Если источник временно не работает, API продолжает отдавать последнее успешно сохранённое расписание, а интерфейс показывает предупреждение и прежнюю дату обновления. До первого успешного импорта список пуст, что явно отображается в интерфейсе.

Идентификатор занятия вычисляется из нормализованных полей. Первичный ключ исключает дубли; полная замена снимка удаляет отменённые и заменяет изменённые занятия. Повторная загрузка тех же данных не увеличивает число записей. WAL позволяет читать прежнюю версию, пока новая записывается. Каждое соединение включает внешние ключи; пользовательские параметры передаются в SQL через placeholders.

Обновление выполняется в единственном процессе API (`--workers 1`). Не масштабируйте контейнер бэкенда без вынесения планировщика в отдельный сервис. Для принудительной повторной загрузки достаточно `docker compose restart backend`: первая попытка начнётся сразу.

## Особенности таблиц

- Поддержаны сетки институтов: дни и время слева, группы и подгруппы по столбцам, аудитория справа от предмета; объединённые ячейки раскрываются с сохранением их границ.
- Для ИБО поддержаны дни, записанные вертикально и снизу вверх, английские названия дней, преподаватель в следующей строке и явное уточнение времени в строке занятия.
- В двухстрочных сетках верхняя строка по умолчанию считается числителем / нечётной неделей, нижняя — знаменателем / чётной. Настройка `UPPER_ROW_WEEK=even` меняет соответствие. Это соглашение о расположении строк, а не вычисление учебной недели по календарю. В интерфейсе по умолчанию показаны **все недели**.
- Одинаковые записи на обеих неделях объединяются. Разные аудитории, подгруппы или преподаватели сохраняются отдельно.
- В интерфейсе одинаковые занятия разных подгрупп объединяются в одну карточку со всеми исходными записями. При выборе подгруппы сохраняются общие записи и записи без понятного указания подгруппы.
- Название, тип и ФИО извлекаются из текста; отсутствующие значения не выдумываются. Исходный текст, файл, лист и координата ячейки сохраняются у каждого занятия. Объединённый предмет не попадает в поле аудитории.
- Произвольные текстовые условия, исключения и даты сохраняются в названии, примечаниях или исходной записи. Они **не превращаются автоматически в календарные события**. Интерфейс показывает недельный шаблон, а не гарантированный календарь на конкретную дату; для отдельных дат сверяйтесь с источником. Календарь учебных недель и праздников университетом через эти таблицы явно не предоставлен.
- Файлы МИСИС могут менять оформление. Поддержка проверена на девяти файлах от 07.09.2026; новый формат может потребовать изменения адаптера в `backend/app/parser.py`. Неподдержанные справочные листы отражаются в `warnings`. До принятия нового формата сохраняется последняя успешная версия.

Также поддержан простой табличный XLSX для интеграций и тестов: первая строка содержит `Группа`, `День`, `Начало`, `Конец`, `Предмет`; необязательные поля — `Тип`, `Преподаватель`, `Аудитория`, `Подгруппа`, `Неделя`, `Примечание`. Время — `09:00`, день — название на русском или число 0–6, неделя — `all`, `odd`, `even` либо «все», «нечётная», «чётная».

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт приложения на хосте |
| `SOURCE_URL` | `https://misis.ru/students/` | HTML-страница или прямая ссылка на XLS/XLSX |
| `SOURCE_LINK_PATTERN` | пусто | Регулярное выражение для адреса файла или текста ссылки; например `itkn` для ИКН |
| `UPDATE_INTERVAL_SECONDS` | `14400` | Пауза между импортами, минимум 60 секунд |
| `REQUEST_TIMEOUT_SECONDS` | `60` | Тайм-аут сетевых операций |
| `MAX_DOWNLOAD_BYTES` | `31457280` | Максимальный размер каждого ответа, 30 МиБ |
| `DATABASE_PATH` | `/data/misisync.sqlite3` | Путь к базе внутри контейнера |
| `ENABLE_SCHEDULER` | `true` | Автоматические обновления; `false` для разработки и тестов |
| `UPPER_ROW_WEEK` | `odd` | Чётность верхней строки двухстрочного блока |
| `NUXT_API_BASE` | `http://backend:8000` | Адрес Python API, доступный серверу Nuxt |

`.env`, локальная база, окружение Python и зависимости исключены из Git. Для исходного публичного расписания секреты не нужны. Внешний Google Fonts используется только для шрифта; при его недоступности включается системный шрифт.

## API

API доступен через тот же адрес, что и интерфейс:

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/api/groups` | Все названия групп, включая группы без занятий |
| GET | `/api/catalog` | Группы с `institutes` и `education_level` для поиска |
| GET | `/api/schedule?group=БИВТ-26-6-1` | Недельное расписание группы |
| GET | `/api/schedule?group=БИВТ-26-6-1&weekday=1` | Вторник; 0 — понедельник, 6 — воскресенье |
| GET | `/api/schedule?group=БИВТ-26-6-1&subgroup=1` | Первая подгруппа, совместные занятия и записи без уточнения; `subgroup_ids` содержит распознанные номера |
| GET | `/api/status` | `last_success`, `last_attempt`, `last_error`, `updating`, количество групп и занятий, источник и предупреждения |
| GET | `/api/health` | Проверка доступности API и SQLite |

Неизвестная или невыбранная группа возвращает пустой массив. Недопустимый день возвращает HTTP 422. Время занятий задано в Москве, отметки обновления — ISO 8601 UTC; интерфейс переводит их в МСК. Healthcheck проверяет работоспособность сервиса, а готовность данных определяется через `last_success`.

```sh
curl --get 'http://localhost:3000/api/schedule' --data-urlencode 'group=БИВТ-26-6-1' --data-urlencode 'weekday=1'
```

## Разработка без Docker

Нужны Python 3.12+ и Node.js 22.12+.

```sh
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements-dev.txt
PYTHONPATH=backend DATABASE_PATH=data/misisync.sqlite3 .venv/bin/uvicorn app.main:app --reload
```

В другом терминале:

```sh
cd frontend
npm ci
NUXT_API_BASE=http://127.0.0.1:8000 npm run dev
```

В этом режиме переменные Python задаются в окружении команды: файл `.env` автоматически читает Docker Compose, а не Python. Импорт отдельно от API, когда API остановлен: `PYTHONPATH=backend .venv/bin/python -m app`.

## Проверки

```sh
cd backend
../.venv/bin/pytest -q
```

Тесты используют временные базы, небольшие сгенерированные таблицы и имитацию HTTP. Проверяют поля и объединённые ячейки, подгруппы и чётность, повторный импорт, замену изменённых занятий, SQL-откат, сохранность после перезапуска, ошибки сети и файлов, частичный сбой нескольких институтов, ограничения размера и ответы API. Тесты не зависят от доступности сайта МИСИС.

```sh
cd frontend
npm run build
npm run typecheck
npm test
```

Проверить конфигурацию контейнеров: `docker compose config --quiet`. Проверка полного запуска контейнеров требует запущенного Docker Engine.
